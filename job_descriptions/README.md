# Job Descriptions (interview context)

Drop each target role's JD here as a markdown file **before that interview**, e.g.:

```
job_descriptions/senior_swe_acme.md
ai_engineer_globex.md
```

buddy-core automatically ingests the most recent `.md` in this folder and uses it to tailor answers (JD-aware emphasis per the prompt contract). No app restart needed — the brain re-embeds on content change at session start.

## Recommended format

```markdown
# <Role Title> — <Company>

<paste the JD verbatim here>

## Notes (optional)
- Team/domain signals, stack hints from the listing page, interview loop details
```

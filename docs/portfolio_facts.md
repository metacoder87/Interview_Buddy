# GM Cube Designs Portfolio Facts

Curated from the public portfolio on 2026-08-14. This supplement provides
project evidence for ranking; generated application claims still pass through
the claim ledger.

- Sidekick LLM: privacy-first Electron/React desktop knowledge system for local
  Ollama models, Expert vaults, federated retrieval, grounded answers, durable
  memory, SQLite, and portable local data.
- SYNAPSE: local-first FastAPI/Next.js job intelligence platform that normalizes
  six sources, applies deterministic screening and semantic ranking, and
  produces evidence-checked company dossiers using PostgreSQL and agentic AI.
- Investment Matrix: event-driven cryptocurrency research and paper-trading
  platform with live exchange ingestion, backtesting, portfolio workflows,
  FastAPI, TimescaleDB, Redis, Next.js, and local AI risk analysis.
- Holdem-Trainer: quantitative poker engine with Monte Carlo equity, EV and ICM
  analysis, CFR+ solving, adaptive drills, FastAPI, PostgreSQL, Docker, and
  production-shaped observability.
- Qdrant Search: document-first semantic search console with deterministic
  seeding, ranked document results, retrieval evaluation, and human feedback
  capture using Qdrant, FastAPI, TypeScript, and React.
- Learning Tree: local-first learning platform with streamed lesson generation,
  backend-scored mastery, durable learner state, React Three Fiber, FastAPI,
  TypeScript, and SQLite.
